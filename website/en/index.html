🌱 Plant Inventory App — Serverless on AWS

Production-grade serverless application for managing garden care plans. Step Functions orchestrates 11 Lambdas to generate yearly care schedules using Anthropic Claude AI, then verifies them monthly against weather forecasts via OpenWeatherMap and sends HTML email proposals through SES. Plant database (~1800 species) imported from Wikidata SPARQL. Frontend hosted on S3 + CloudFront with HTTPS. Full IaC with Terraform Workspaces and zero-keys CI/CD via GitHub Actions + OIDC.

Lambda DynamoDB Step Functions API Gateway EventBridge SES SSM CloudFront S3 Terraform GitHub Actions Claude AI Python
