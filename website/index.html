🌿 IntegraHolistic — aplikacja dla gabinetów holistycznych

🌱 Plant Inventory App — serverless na AWS

Produkcyjna aplikacja serverless do planów pielęgnacji ogrodu. Step Functions steruje 11 funkcjami Lambda, które z pomocą Anthropic Claude AI układają roczny kalendarz pielęgnacji, co miesiąc weryfikują go z prognozą pogody (OpenWeatherMap) i wysyłają propozycje mailem przez SES. Baza ~1800 gatunków roślin zaimportowana z Wikidata (SPARQL). Front na S3 + CloudFront z HTTPS, całość w Terraform Workspaces, CI/CD bez kluczy przez GitHub Actions + OIDC.

Lambda DynamoDB Step Functions API Gateway EventBridge SES SSM CloudFront S3 Terraform GitHub Actions Claude AI Python
